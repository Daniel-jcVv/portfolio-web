## Tech stack

React 18 · Vite · TailwindCSS · EmailJS (contact form) · Vercel (deploys automatically from `main`)

## Run locally

```bash
npm ci
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

The contact form needs these variables in a `.env` file (never commit it):

```
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
